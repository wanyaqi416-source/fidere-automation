## 修正后的 Exchange Oracle

完整兑换只有在以下证据一致时才通过：

1. 安全密钥只验证一次并成功。
2. 转出和转入余额按最终报价变化。
3. 新兑换记录与当前账号、币种对、转出金额、到账金额、执行时间窗口和完成状态一致。
4. 从交易流水列表取得唯一 `TXN-*` 流水编号。
5. 打开对应“兑换 详情”，从详情取得唯一 `OTC-*` 兑换订单编号。

`TXN-*`与`OTC-*`是不同编号：前者是`ledgerTransactionId`，后者是`exchangeOrderId`，不得通过替换前缀推导。

## 修正后的详情读取结果

2026-08-26 的只读复核已唯一找到目标成交记录。交易流水列表的“交易编号”显示`TXN-*`；点击该记录后打开“兑换 详情”，详情“交易编号”显示真实`OTC-*`。详情同时提供状态、实际到账、手续费、创建/完成日期、兑换前后金额及币种。
